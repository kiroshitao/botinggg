# 🤖 MentBot — Telegram-бот каталога менторов

## Структура проекта

```
mentbot/
├── main.py              # Точка входа
├── config.py            # Конфигурация (читает .env)
├── database.py          # Все операции с БД (SQLite)
├── keyboards.py         # Все клавиатуры (inline + reply)
├── states.py            # FSM-состояния
├── handlers/
│   ├── user.py          # Каталог, карточка ментора, заявки
│   ├── mentor.py        # Принятие/отклонение заявок, CRM-действия
│   └── admin.py         # Управление менторами и категориями, статистика
├── .env                 # Токен и настройки (не коммитить!)
└── mentors.db           # SQLite база данных (создаётся автоматически)
```

## Быстрый старт

### 1. Настройте `.env`

```env
BOT_TOKEN=ваш_токен_от_BotFather
ADMIN_IDS=ваш_telegram_id,другой_admin_id
ADMIN_GROUP_ID=-1001234567890
```

- **BOT_TOKEN** — получить у [@BotFather](https://t.me/BotFather)
- **ADMIN_IDS** — ваш числовой Telegram ID (узнать через [@userinfobot](https://t.me/userinfobot))
- **ADMIN_GROUP_ID** — ID группы с темами для администратора (опционально)

### 2. Запустите бота

```bash
python main.py
```

## Функциональность

### Для пользователей
- 📚 Многоуровневый каталог менторов (неограниченная вложенность)
- 👤 Карточка ментора с фото, описанием, опытом, стоимостью
- 📩 Кнопка «Связаться с ментором» — создаёт заявку автоматически
- ✉️ Кнопка «Написать ментору» — прямая ссылка на Telegram ментора

### Для менторов
- 🔔 Уведомление о новой заявке с данными ученика
- ✅ Кнопки «Принять» / «Отклонить» заявку прямо в чате

### Для администратора
- ⚙️ Добавление/редактирование/удаление менторов
- 🗂 Управление категориями (любая вложенность)
- 🔴/🟢 Включение/отключение приёма заявок у ментора
- 📊 Статистика: заявки, конверсия, сделки, комиссии
- 📋 Все заявки отображаются в Telegram-группе с темами (по одной теме на ментора)

### CRM-функции (в группе администратора)
- 🤝 Отметить, что связь состоялась
- 💰 Отметить закрытие сделки
- 💵 Отметить получение комиссии

## Настройка Telegram-группы с темами

1. Создайте группу в Telegram
2. Включите **Topics** (Темы) в настройках группы
3. Добавьте бота в группу как администратора
4. Для каждого ментора создайте тему с его именем
5. Узнайте ID группы (через [@getmyid_bot](https://t.me/getmyid_bot))
6. Укажите `ADMIN_GROUP_ID` в `.env`
7. При добавлении ментора через бота укажите `topic_id` темы (через редактирование поля)

## База данных

SQLite файл `mentors.db` создаётся автоматически при первом запуске.

Таблицы:
- `categories` — иерархические категории (parent_id, level)
- `mentors` — менторы с привязкой к категории и теме группы
- `applications` — заявки с полным CRM-трекингом
